# ¿Quién decide cuánto valgo?

Charla-taller para **madres, padres y cuidadores** de niños y niñas de **6 a 11 años**.  
**Cedric Milles · Psicología · Orientación · Rendimiento**

## Cómo proyectar la presentación

1. Abre `index.html` en Chrome, Edge o Firefox.
2. Pantalla completa con **F**.
3. Avanza con **→** / **Espacio**; retrocede con **←**.

También puedes usar el PowerPoint editable:

- `materiales/Quien_decide_cuanto_valgo_Presentacion.pptx` (importable en Canva)

## Estructura de la sesión (60 min)

1. **0–40 min** — Explicación participativa: conceptos, desarrollo 6–11, ciclo cognitivo, feedback, autonomía, comparación y acoso, brújula y semáforo.
2. **40–60 min** — Dos talleres:
   - Laboratorio de frases
   - Ensayo de acompañamiento (error cotidiano o burlas repetidas)
3. Cierre con plan de 7 días.
