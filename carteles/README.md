# Carteles Cedric Milles

Carteles alineados con el material corporativo (brújula, paleta y tono editorial).

## Cartel principal (recomendado)

| Archivo | Público | Notas |
|---|---|---|
| `cartel-servicios-familias-qr.png` | Niños, adolescentes y familias | QR → https://cedricmilles.com/es/servicios/ |

## Pack corporativo (normativa)

| Archivo | Enfoque | Mensaje |
|---|---|---|
| `cartel-institucional-cedric-milles.png` | Corporativo | Psicología para comprender · Orientación para decidir · Rendimiento para avanzar |
| `cartel-bienestar-cedric-milles.png` | Bienestar | No necesitas tenerlo todo claro para empezar a avanzar |
| `cartel-claridad-cedric-milles.png` | Claridad | Baja el ruido. Recupera perspectiva |

## Especificaciones

- A3 vertical (297 × 420 mm), 200–300 dpi según archivo
- Paleta: `#092D4A` · `#315F8D` · `#4A8BC7` · `#53616F`
- Vista previa: `index.html`

## Regenerar

```bash
python3 carteles/generar_carteles.py
python3 carteles/generar_cartel_servicios_familias.py
```

QR: `pip install qrcode[pil]`

## Archivo (borradores colegio — no usar salvo que lo pidas)

Los PNG `cartel-colegios-*` y `cartel-escolar-*` son pruebas anteriores con enfoque colegio; no forman parte del material recomendado.
